# OPay Field Operations App — User Guide

**Made by Hamvida Tech**

---

## 1. Access Portal

On open you will see:

1. **Creator** — admin master (password only)
2. **Staff Login / Register** — CDL, CDLM, SM, RM
3. **DH Oversight** — analytics & transfers (no region/state required)
4. **Play as Guest** — try the simulator

Language selector is at the **bottom** (default **English**). Changing language affects only your session.

---

## 2. Staff

### Register
1. Choose role  
2. Enter Login ID + Name  
3. Select **Male/Female**  
4. Select Region + State (full Nigeria list; Lagos North/South supported)  
5. RM can multi-select regions/states  
6. Create password  

### Login
Use Login ID + password.

### If blocked by duplicate check
- Exact match → use original account  
- Conflict → contact Creator/Admin  
- Same name only is allowed when Login IDs differ  

---

## 3. DH

### Login / Register
Login ID + Name + Gender + password only.

### Dashboard tabs
- **Analytics** — national/regional performance  
- **Staff Transfers** — change staff Region/State with reason + audit  
- **SM / RM Map** — pick a state; see SM & RM in charge  
- **Gender** — male/female workforce mix by role  
- **Game Studio** — paste SOP → recommended game types  

---

## 4. Creator

Password: configured internal Creator key.

Tools:
- **Game Studio** — multi-game catalog, policy suggestions, version rollback  
- **Staff Admin** — registry, manual create, gender stats, lock/activate  
- **Reset Pass** — field account recovery console  
- Full simulator access  

---

## 5. Career Run (default live game)

1. Choose human male/female character  
2. Run 3 lanes; collect ₦; answer decision gates  
3. Right answers → richer  
4. Wrong answers → poorer  
5. Critical failure → choose fate:
   - Sacked by OPay  
   - Merge with Big CDL  
   - Join BD / Direct POS  
   - Sell merchants & resign  

---

## 6. Feedback

Use **Feedback** to leave notes. Creator can mark Open / In Progress / Done.
